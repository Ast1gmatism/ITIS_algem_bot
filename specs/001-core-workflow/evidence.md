## Исходный RED

- Команда: `python -m pytest -q`.
- До реализации: exit code 4, `ModuleNotFoundError: No module named 'algem_bot.adapters'` при загрузке контрактов.
- Это исход отсутствующего программного контракта, а не поведенческая бизнес-проверка.

## Поведенческий RED при проверке границ

После первого GREEN из 74 тестов добавлены проверки прав и сохранности протокола. Запуск `python -m pytest tests/test_guards.py -q` дал **6 failed, 10 passed**.

Выявлены и затем исправлены:

- bootstrap не должен перекрывать явное снятие роли в ведомости;
- `True` не является допустимым Telegram-actor ID;
- желаемое значение outbox обязано совпадать с текущим локальным полем;
- ошибочные производные ячейки не должны становиться источником данных или останавливать перерасчёт;
- публичное представление должно показывать автоматический допуск 🔴;
- снятие роли Админа должно проверяться при выполнении действия, несмотря на bootstrap-настройку.
