# Алгем — запись на номера и учёт выходов к доске

**Стадия:** основные продуктовые правила уточнены; реализация ещё не начата.  
**Версия документации:** 0.2 от 19 ноября 2026 года.  
**Репозиторий:** [Ast1gmatism/ITIS_algem_bot](https://github.com/Ast1gmatism/ITIS_algem_bot).

## Главный результат

Студент занимает номер без переписки в общем чате. Ответственный видит, кто на что записан, сколько у человека выходов и баллов, кому стоит выходить, и подтверждает фактическую сдачу без ручного сопоставления чата с таблицей.

> Добавили номера → студенты заняли их кнопками → ответственный видит готовый список → подтверждает фактическую сдачу → выходы, баллы и ведомость обновляются автоматически.

Управление эталоном, светофор и анти-тишина обслуживают этот сценарий, а не являются самостоятельной главной целью продукта.

## Две рабочие зоны

- **Общий чат:** одно обновляемое табло, свободные номера, ФИО бронировавших и кнопки записи.
- **Личная админ-панель:** задачи, брони, ФИО, выходы, баллы, приоритеты и подтверждение фактической сдачи.

## Основные правила

- Одна кнопка на номер; первая свободная буква назначается автоматически.
- Одна активная бронь на студента; повторное нажатие на свой номер отменяет её.
- Бронь ничего не начисляет; сдачу подтверждает только ответственный.
- Сначала 20-секундное окно для 🟢, затем допускаются 🟡. Если нет зарегистрированных 🟢, способных взять бронь, окно пропускается.
- Доступ 🔴 определяется автоматически; ручного тумблера нет.
- Максимум выходов и средний темп считаются по активным: `Студент` и `Админ`.
- Студент выбирает ФИО из ведомости; привязку к Telegram подтверждает ответственный.
- `Внесистемы` не привязываются к боту и не бронируют, но их выходы учитываются по подтверждению ответственного.
- Google Таблица — источник правды. Ручное число — готовый итог, уже учитывающий выходы.
- На новую порцию задач — один общий пинг приоритетным; клики не создают сообщений в чат.
- Отдельной отмены сдачи в первой версии нет: счётчик исправляется в таблице.
