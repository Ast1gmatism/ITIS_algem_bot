# Алгем — запись на номера и учёт выходов к доске

**Стадия:** фиксация требований, реализация ещё не начата.  
**Версия документации:** 0.1 от 19 ноября 2026 года.  
**Репозиторий:** [Ast1gmatism/ITIS_algem_bot](https://github.com/Ast1gmatism/ITIS_algem_bot).

## Главный результат

Студент занимает номер без сообщений в общем чате. Ответственный видит в одном месте, кто на что записан, сколько у человека выходов и баллов, кому стоит выходить, и подтверждает фактическую сдачу без ручного сопоставления чата с таблицей.

> Добавили номера → студенты заняли их кнопками → ответственный видит готовый список → подтверждает фактическую сдачу → выходы, баллы и ведомость обновляются автоматически.

Управление эталоном, светофор и анти-тишина — вспомогательные механизмы этого сценария, а не самостоятельная главная цель продукта.

## Основные возможности по ТЗ

- Одно обновляемое табло Telegram вместо записи на номера сообщениями.
- Кнопка на номер задачи и автоматическое назначение первой свободной буквы.
- Одна активная бронь на студента; повторное нажатие на свой номер отменяет бронь.
- Привязка Telegram ID к ФИО; постоянная роль отдельно от динамического приоритета.
- Подтверждение сдачи ответственным в один тап либо выбор другого сдавшего.
- Автоматический расчёт выходов, баллов и светофора.
- Двусторонняя синхронизация с Google Таблицей и ручные корректировки через неё.
- Защита от повторного начисления и конфликтов конкурентных действий.

## Планируемый стек

- Python 3.11+.
- aiogram 3.x.
- gspread-asyncio и сервисный аккаунт Google Cloud.
- Pydantic v2.
- RAM + локальный `state.json` с атомарной записью.
