# Алгем — запись на номера и учёт выходов к доске

**Стадия:** M1 — проверяемое ядро и offline-сценарий реализованы; работающего Telegram-бота пока нет.  
**Продуктовая спецификация:** 0.2 от 19 ноября 2026 года.  
**Версия пакета ядра:** 0.1.0.  
**Репозиторий:** [Ast1gmatism/ITIS_algem_bot](https://github.com/Ast1gmatism/ITIS_algem_bot).

## Главный результат продукта

Студент занимает номер без переписки в общем чате. Ответственный видит, кто на что записан, сколько у человека выходов и баллов, кому стоит выходить, и подтверждает фактическую сдачу без сопоставления чата с таблицей.

> Добавили номера → студенты заняли их кнопками → ответственный видит готовый список → подтверждает фактическую сдачу → выходы, баллы и ведомость обновляются автоматически.

Управление эталоном и анти-тишина обслуживают этот сценарий, а не являются самостоятельной главной целью.

## Что уже реализовано в M1

- Строгие Pydantic-модели людей, привязок, задач и сохраняемого состояния.
- Баллы, светофор, максимум и среднее только по активным, стартовое исключение.
- Выбор записи и одобрение Telegram-привязки на уровне прикладных операций.
- Одна бронь, автовыбор буквы, 20-секундное окно 🟢 и автоматический допуск 🔴.
- Подтверждение сдачи, другой сдавший, внесистемный без TG_ID, снятие его остальных броней.
- Защита от конкурентной брони, повторного начисления и старой сессии.
- Атомарное JSON-хранилище, сохранение неотправленных изменений и восстановление после рестарта.
- Согласование с ведомостью через программный порт: приоритет новых внешних итогов, распознавание старых снимков, ревизии и неопределённый результат записи.
- Чистые HTML-представления публичной и административной зон, без сетевого транспорта.
- Offline-демо, приёмочные/регрессионные/property-based тесты и конфигурация CI.

**Ведомость в M1 — in-memory адаптер, не Google Sheets.** Событие общего пинга формируется, но ещё не отправляется в Telegram.

## Что ещё не реализовано

- aiogram handlers, настоящий поллинг, callbacks, редактирование сообщений и доставка пингов.
- Подключение реальной Google Таблицы и сопоставление её физических строк/колонок.
- Фоновые 30-секундный Pull, debounce Push и обновление сообщений по таймеру.
- Постоянный хостинг и рабочие секреты.

M1 — не готовый полный MVP. Подробная граница покрытия: [трассировка требований](docs/TRACEABILITY.md).

## Быстрый запуск offline-демо

Требуется **Python 3.11+**. Для демо не нужны токены, сервисный аккаунт или доступ к сети после установки зависимостей.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m algem_bot.demo
```

На Windows активация: `.venv\Scripts\activate` вместо `source ...`.

Демо использует синтетические ФИО/TG_ID и временный `state.json`, показывает обе зоны, сдачу другим человеком, внесистемного без Telegram и приоритет ручного итога «8, не 9». Рабочая ведомость не читается и не изменяется.

Альтернативная команда после установки: `algem-demo`.

## Проверки

```bash
python -m pytest --cov=algem_bot --cov-report=term-missing
ruff check .
ruff format --check .
mypy src/algem_bot
```

В тестах блокируются DNS и открытие сетевых соединений. JSON-файлы создаются только во временных каталогах тестов. Текущий локальный результат и версии зависимостей: [evidence](specs/001-core-workflow/evidence.md).

CI настроен на Python 3.11, 3.12 и 3.13. Для коммита ядра `796da37` [все три job прошли](https://github.com/Ast1gmatism/ITIS_algem_bot/actions/runs/44596120729); локально проверки выполнены на Python 3.13. Результат конкретного запуска не является обещанием успешности будущих изменений.

## Продуктовые правила

- Публичная зона — запись; личная админ-панель — подтверждения и показатели.
- Бронь ничего не начисляет; сдачу подтверждает только ответственный.
- Максимум и среднее — по `Студент`/`Админ`, а не по наличию Telegram-привязки.
- Внесистемные не бронируют, но их фактические выходы учитываются.
- Ручного тумблера 🔴 и отдельной отмены сдачи нет.
- Google Таблица в полном продукте — источник правды, ручное число — готовый итог.
- На порцию новых задач — один общий пинг приоритетным.

## Данные и секреты

Не коммитить токен бота, ключ сервисного аккаунта, SSH-ключи, `.env`, рабочий `state.json`, реальные ФИО/TG_ID и выгрузки ведомости. `.gitignore` исключает секреты и генерируемые файлы, но не заменяет проверку состава коммита.

Постоянный хостинг не выбран. JSON-вариант рассчитан на один процесс с сохраняемым диском; `asyncio.Lock` не защищает от второго процесса или ручного редактора Google Sheets.
